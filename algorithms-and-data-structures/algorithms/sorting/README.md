# Sorting Algorithms

Sorting is the process of arranging elements in a specific order,
usually ascending or descending.

## Complexity

Sorting algorithms can be analyzed using:

- Time Complexity
- Space Complexity

### Time Complexity

- Best Case
- Average Case
- Worst Case

### Space Complexity

Describes how much additional memory an algorithm requires.

## Properties

Sorting algorithms can also be categorized by:

- In-place
- Out-of-place
- Stable
- Unstable
- Adaptive
- Non-adaptive
- Comparison-based
- Non-comparison-based
