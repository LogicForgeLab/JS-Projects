# Searching Algorithms

Searching algorithms are techniques used to find a specific element,
value, or piece of information within a data structure.

The main goal of a searching algorithm is to find the target efficiently
while minimizing the number of operations required.

## Overview

Searching algorithms can work differently depending on the structure
and organization of the data.

Some algorithms check elements one by one, while others use properties
such as sorted data to reduce the search space.

## Common Searching Approaches

- Sequential searching
- Divide and conquer searching
- Block-based searching
- Hash-based searching
- Graph and tree searching

## Important Concepts

When working with searching algorithms, it is important to understand:

- Whether the data must be sorted
- How the search space is reduced
- Time complexity
- Space complexity
- Best, average, and worst-case performance

## Complexity

The efficiency of a searching algorithm is usually described using
Big O notation.

Common complexities include:

```text
O(1)
O(log n)
O(√n)
O(n)
O(n log n)
```
